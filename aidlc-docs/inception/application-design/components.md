# コンポーネント — TaskBoard Mini

## 概要

Vue 3 SPA。画面は **ボード** を中心に **列** と **カード** を再帰的に配置する。永続化は **サービス層**（Repository）経由とし、UI コンポーネントはストアに依存する。

---

## C1 — `App`（ルート）

| 項目 | 内容 |
|------|------|
| **目的** | アプリシェル、グローバルスタイル・レイアウトの土台 |
| **責務** | 子に `BoardView` をマウント；初期ロード時にストアの **hydration**（Repository から読込）をトリガー |
| **インターフェース** | 子コンポーネントへ `provide`（必要ならテーマのみ）。ビジネス状態は Pinia に集約 |

---

## C2 — `BoardView`

| 項目 | 内容 |
|------|------|
| **目的** | 複数 **列** の横並びレイアウト |
| **責務** | `columns` の並び順表示；列追加 UI の配置；空ボード時のガイド（TB-07） |
| **インターフェース** | Pinia `useBoardStore()` から列・操作を取得 |

---

## C3 — `ColumnView`

| 項目 | 内容 |
|------|------|
| **目的** | 1 列のヘッダーとカード一覧 |
| **責務** | 列名表示・列名編集・列削除操作；配下の `CardItem` 一覧；**カード追加** ボタン |
| **インターフェース** | `columnId` を props で受け取る |

---

## C4 — `CardItem`

| 項目 | 内容 |
|------|------|
| **目的** | 1 枚のカード表示と編集・削除 |
| **責務** | タイトル（＋任意の短い本文）表示；インライン編集またはモーダルは実装選択；削除確認は UX 方針に従う |
| **インターフェース** | `cardId` を props |

---

## C5 — `CardCreateForm`（インラインまたは `ColumnView` 内）

| 項目 | 内容 |
|------|------|
| **目的** | 新規カードのタイトル入力と確定 |
| **責務** | バリデーション（空タイトル不可等）；確定時にストアの **createCard** を呼ぶ |

---

## 非 UI モジュール（コンポーネント外）

- **Pinia store**: `board` — ドメイン状態の単一ソース（後述 `services.md` と連携）。
- **型・定数**: `types/board.ts` 等（実装フェーズで配置）。
