# ペルソナ — TaskBoard Mini

## P1 — けん（主ペルソナ）★

| 項目 | 内容 |
|------|------|
| **属性** | 30 代、個人で働く知識労働者（開発・企画・執筆など） |
| **目標** | 自分のタスクを列で区切り、今日やることと後でやることを迷わず分けたい |
| **動機** | サーバー契約やログインなしで、ブラウザだけですぐ使い始めたい |
| **課題** | 付箋アプリは重い／複雑。シンプルなカンバンが欲しい |
| **技術** | モダンブラウザは使える。インストール不要が好み |
| **成功** | 再読込してもタスクが残り、列ごとに整理できている |

**関連ストーリー**: Epic「MVP タスクボード」配下のすべて（TB-01〜TB-07）。

---

## P2 — みか（副ペルソナ・参照）

| 項目 | 内容 |
|------|------|
| **属性** | 20 代、学習・副業プロジェクトでタスクを追いたい人 |
| **目標** | 学習タスクを「未着手／進行／完了」に分けて可視化したい |
| **動機** | 無料・静的ホストで公開してもコストをかけたくない |

**関連ストーリー**: TB-01〜TB-06（P1 と同一機能で足りる）。TB-07 のジャーニー補助は P1/P2 両方に該当しうる。
