## Epic E-MVP — MVP タスクボード

初版で静的ホスト可能な Vue アプリとして、列・カードの CRUD とブラウザ永続化を提供する。

---

### TB-01 — 列を複数表示する

**As a** 知識労働者（P1）  
**I want to** 複数の列を同時に見る  
**So that** ステータスや段階でタスクを区別できる

**受け入れ基準**

1. 画面上に **2 本以上の列** が横並び（またはレイアウト上同時表示）される。  
2. 各列に **列名（title / label）** が識別可能な形で表示される。  
3. スコープ外: **drag-and-drop** による列間移動は不要（要件 3.2）。

---

### TB-02 — 列を管理する

**As a** 知識労働者（P1）  
**I want to** 列を追加・名称変更・削除する  
**So that** 自分のワークフローに合わせて列セットを調整できる

**受け入れ基準**

1. ユーザー操作で **列の追加（add column）** ができる。  
2. 既存列について **名称変更（rename）** ができる。  
3. 不要な列を **削除（delete column）** できる。削除時、その列に属するカードの扱いは実装で定義し、**データが黙って消える**場合は確認または明示的な挙動が分かること（最低限: 要件と矛盾しない）。  
4. 常に **少なくとも 1 列** が残る、または空ボードの扱いが要件と整合する（要件 3.1.1 の「複数列」と整合）。

---

### TB-03 — カードを追加する

**As a** 知識労働者（P1）  
**I want to** 選んだ列にカード（タスク）を追加する  
**So that** 新しい作業項目をボードに載せられる

**受け入れ基準**

1. **カード作成（create card）** 用の UI から、**タイトルまたは本文** 等の最低限テキストを入力できる。  
2. 新規カードは **ちょうど 1 つの列（column）** に属する。  
3. 作成直後、その列の一覧に **新カードが表示** される。

---

### TB-04 — カードを編集する

**As a** 知識労働者（P1）  
**I want to** 既存カードの内容を編集する  
**So that** タスクの内容を更新できる

**受け入れ基準**

1. 既存カードについて **編集（edit / update）** ができる。  
2. 保存または確定後、**表示内容が更新** される。

---

### TB-05 — カードを削除する

**As a** 知識労働者（P1）  
**I want to** 不要なカードを削除する  
**So that** ボードを整理できる

**受け入れ基準**

1. カードごとに **削除（delete）** 操作ができる。  
2. 削除後、そのカードは一覧に **表示されない**。

---

### TB-06 — ボード状態をブラウザに永続化する

**As a** 知識労働者（P1）  
**I want to** ページを再読み込みしてもボードが復元される  
**So that** 作業を継続できる

**受け入れ基準**

1. 列・カードの状態が **ブラウザ内ストレージ**（`localStorage` または `IndexedDB` のいずれか）に保存される。  
2. **ページリロード（reload）** 後、前回の列とカードが **復元** される。  
3. **PBT**: **serialize / deserialize** または **save / load** の **round-trip** 性質は Functional Design・実装で特定し、プロパティベーステストの対象とする（要件 4.1）。

---

### TB-07 —（補助）初回訪問から最初のカードまで（ジャーニー補助）

**As a** 新規利用者（P1 / P2）  
**I want to** 初めて開いてから最初のカードを登録するまでの流れが途切れない  
**So that** すぐにタスク管理を始められる

**受け入れ基準**

1. **初回表示** で、空または既定列が表示され、**追加操作への導線** が分かる。  
2. TB-03 の **create card** が、初回セッション内で **完了可能** である（エラーでブロックされない通常系）。  
3. 本ストーリーは **E2E または手動シナリオ** の補助として用い、TB-01〜TB-06 の下位詳細ではない。
